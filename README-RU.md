# Закрыть другие вкладки+

Браузерное расширение, позволяющее закрывать/закреплять/откреплять/группировать/разгруппировать несколько вкладок сразу, фильтруя их по различным свойствам.

## Фильтрация по рабочим пространствам в Opera

В дополнение к группам вкладок Opera также предлагает рабочие пространства. **Close Other Tabs+** для Opera поддерживает фильтрацию по рабочим пространствам наряду с группами вкладок — вы можете выбрать воздействие на вкладки в текущем рабочем пространстве, во всех рабочих пространствах или в других рабочих пространствах. Чтобы настроить это, найдите параметр **На какие рабочие пространства воздействовать** в настройках расширения.

## Воздействовать на вкладки по состоянию группированности в Яндекс Браузере

В Яндекс Браузере каждая вкладка принадлежит какой-либо группе — даже если это просто основная (стандартная) группа. В результате параметр **Несгруппированные** в настройке **Воздействовать на вкладки по состоянию группированности** не будет работать должным образом, поскольку по-настоящему не сгруппированных вкладок не существует.

## Инструкция по сборке

1. `git clone https://github.com/loftyshaky/close-other-tabs-plus`
2. `cd` в клонированный репозиторий
3. `npm install`
4. `npm run prod_test` (Chrome) / `npm run prod_test_edge` (Edge) / `npm run prod_test_opera` (Opera) / `npm run prod_test_yandex` (Yandex Browser) / `npm run prod_test_firefox` (Firefox)
